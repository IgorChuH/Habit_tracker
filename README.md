# Habit Tracker API

Веб-приложение для отслеживания полезных привычек, вдохновленное книгой Джеймса Клира "Атомные привычки". Проект представляет собой бэкенд-часть SPA с интеграцией Telegram для отправки напоминаний.

## Технологии

- **Python 3.13**
- **Django 4.2** - основной фреймворк
- **Django REST Framework** - создание API
- **PostgreSQL / SQLite** - базы данных
- **Celery** - отложенные задачи и напоминания
- **Redis** - брокер сообщений для Celery
- **Telegram Bot API** - отправка уведомлений
- **JWT / Token Authentication** - аутентификация
- **Flake8** - проверка стиля кода
- **Coverage** - оценка покрытия тестами

## Функциональность

- Регистрация и авторизация пользователей
- CRUD операции для привычек
- Разделение на полезные и приятные привычки
- Связывание привычек (полезная + приятная)
- Публичные и приватные привычки
- Пагинация (5 привычек на странице)
- Валидация данных согласно бизнес-правилам
- Интеграция с Telegram для напоминаний
- Периодические уведомления через Celery
- Покрытие тестами >80%
- Документация API (Swagger/ReDoc)

## Установка и запуск

### Предварительные требования

- Python 3.13+
- PostgreSQL (опционально, можно использовать SQLite)
- Redis (для Celery)
- Telegram Bot Token (получить у @BotFather)

### Пошаговая установка

1. **Клонировать репозиторий**


git clone https://github.com/IgorChuH/Habit_tracker.git
cd habit-tracker 
Создать и активировать виртуальное окружение


python -m venv venv
## Windows
venv\Scripts\activate
## Linux/Mac
source venv/bin/activate
## Установить зависимости


pip install -r requirements.txt

## Запустить сервер Django

python manage.py runserver
