## 🚀 О проекте

**Habit Tracker API** помогает пользователям формировать полезные привычки и избавляться от вредных, основываясь на принципах из книги "Атомные привычки". Проект реализует полный бэкенд для SPA приложения с автоматическими напоминаниями через Telegram.

**Адрес развернутого приложения:** `http://ваш-сервер-адрес`

## 🛠 Технологический стек

### Основные технологии
| Технология | Версия | Назначение |
|------------|--------|------------|
| Python | 3.13 | Язык программирования |
| Django | 4.2 | Основной веб-фреймворк |

| PostgreSQL | 15 | Основная база данных |
| Redis | 7 | Брокер сообщений и кеш |
| Celery | 5.3 | Отложенные задачи |

### Инструменты и библиотеки
- **django-cors-headers** - настройка CORS
- **python-dotenv** - переменные окружения
- **psycopg2-binary** - драйвер PostgreSQL
- **requests** - запросы к Telegram API
- **drf-yasg** - документация API (Swagger)
- **gunicorn** - WSGI сервер для продакшена

### Инфраструктура
- **Docker & Docker Compose** - контейнеризация
- **Nginx** - веб-сервер и прокси
- **GitHub Actions** - CI/CD
- **Flake8** - линтинг кода
- **Coverage** - покрытие тестами

## ✨ Функциональность

### Основные возможности
- ✅ Регистрация и авторизация пользователей (Token Authentication)
- ✅ CRUD операции для привычек
- ✅ Разделение на полезные и приятные привычки
- ✅ Связывание привычек (полезная + приятная)
- ✅ Публичные и приватные привычки
- ✅ Пагинация (5 привычек на странице)
- ✅ Валидация данных согласно бизнес-правилам

### Интеграции
- ✅ Telegram бот для отправки напоминаний
- ✅ Периодические уведомления через Celery (каждый час)
- ✅ Автоматическая документация API (Swagger/ReDoc)

### Безопасность и качество
- ✅ Права доступа (владелец vs другие пользователи)
- ✅ Покрытие тестами >80%
- ✅ Проверка стиля кода (Flake8)
- ✅ CORS настройки для фронтенда

## 🏁 Быстрый старт

### Предварительные требования
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (для запуска в контейнерах)
- [Python 3.13+](https://python.org) (для локального запуска)
- [PostgreSQL 15+](https://postgresql.org) (опционально)
- [Redis 7+](https://redis.io) (для Celery)
- Токен Telegram бота (получить у [@BotFather](https://t.me/BotFather))

### Запуск с Docker (рекомендуется)

#### 1. Клонирование репозитория

git clone https://github.com/yourusername/habit-tracker.git
cd habit-tracker

### 2. Создание файла .env

cp .env.example .env
# Отредактируйте .env, добавьте свои значения

### 3. Запуск контейнеров

# Сборка и запуск всех сервисов
docker-compose up -d --build

# Просмотр логов
docker-compose logs -f

# Создание суперпользователя
docker-compose exec web python manage.py createsuperuser

### 4. Проверка работы
- **Основное приложение:** http://localhost
- **Админ панель:** http://localhost/admin
- **API документация:** http://localhost/swagger/
